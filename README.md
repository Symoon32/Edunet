# EDUNET – Plataforma de Gestión Académica

EDUNET es un sistema de información diseñado para optimizar la gestión académica en instituciones educativas, permitiendo centralizar procesos como el registro de asistencia, la gestión de calificaciones, la publicación de materiales educativos y la comunicación entre los diferentes actores de la comunidad académica.

---

## Proyecto académico
Sistema desarrollado como parte de formación en análisis y desarrollo de software.

---

## Características principales

- Autenticación de usuarios mediante inicio de sesión
- Gestión de usuarios (administradores, docentes, estudiantes y tutores)
- Registro y consulta de calificaciones
- Consulta de calendario académico
- Gestión de tareas y proyectos
- Publicación de material educativo
- Sistema de comunicación mediante mensajes y notificaciones
- Generación de reportes académicos
- Seguimiento académico por parte de padres o tutores

---

## Tipos de usuarios

### Administrador
- Gestión de usuarios
- Configuración del sistema
- Generación de reportes institucionales

### Docente
- Registro de asistencia
- Publicación de calificaciones
- Gestión de clases y materiales educativos

### Estudiante
- Consulta de tareas, calificaciones y materiales
- Acceso al calendario académico

### Padre o Tutor
- Seguimiento del progreso académico
- Consulta de asistencia y calificaciones
- Comunicación con docentes

## Tecnologías utilizadas

- Frontend: HTML, CSS, JavaScript / Angular  
- Backend: Node.js / PHP  
- Base de datos: MySQL  
- Control de versiones: GitHub

## Instalación

1. Clonar el repositorio:

git clone https://github.com/Symoon32/Edunet
2. Acceder al proyecto:

cd edunet-backend 
cd edunet-frontend

3. Instalar dependencias (si aplica):

npm install

4. Ejecutar el proyecto:

npm run dev - backend
ng s - frontend
