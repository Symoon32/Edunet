# Edunet

Edunet es una plataforma educativa diseñada para instituciones en Bogotá. Este proyecto incluye funcionalidades tanto para el frontend como para el backend, proporcionando una solución completa para la gestión académica.

## Características

- **Frontend:** Desarrollado con Angular, ofrece una interfaz de usuario moderna y reactiva.
- **Backend:** Construido con Node.js y Express, gestiona la lógica del negocio y las interacciones con la base de datos.
- **Base de datos:** Utiliza SQLite para el almacenamiento de datos, facilitando un entorno de desarrollo ligero y autocontenido.

## Funcionalidad PWA

Este proyecto se ha mejorado para incluir características de una Progressive Web App (PWA), permitiendo su instalación en dispositivos y el acceso a funcionalidades offline.

### Escáner de QR para Asistencia

Como parte de sus capacidades móviles, la PWA incluye un escáner de códigos QR que permite registrar la asistencia de los estudiantes de manera rápida y eficiente.
